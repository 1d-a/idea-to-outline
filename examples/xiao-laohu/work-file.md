# 《小老虎》编剧档案（第0–3步示例）

本例用来看每一步的交付物长什么样：颗粒度、表格格式、候选写法都照样适用。

> 说明：本例是在本 skill 改成只做小说之前，按连环画（约 40 页）走的一遍。小说版有两处不同：第2步的体量写字数（如“全篇约 8000 字，第一幕约 2000 字、第二幕约 4000 字、第三幕约 2000 字”），分场表的“页数”一列换成“字数”。文中提到的“第4步”是当时的刺激点步骤，现在属于姊妹 skill outline-to-prose。

## 第0步 灵感

### 灵感原文

> 堂吉柯德式故事，一个幻想自己是xxx、被人嘲笑的角色，在危难之际，挺身而出，成为了真正的xxx。

硬性限制：无。

### 火花：全故事的高潮

**假变真的那一刻**：幻想和现实重合的瞬间，也就是整个故事的高潮。前面所有铺垫都朝这一刻走，后面每一步的方案都要保住它。

**情绪要求：极燃**。高潮必须让人热血上头，安静、余韵式的成真不算数。

### 灵感拆解

核心只有三样：幻想自己是某个身份、面对真实的考验时挺身而出、最后真的成为了那个身份。原文里的“被嘲笑”“危难”都是可替换的写法。原型关系：原著《堂吉诃德》是反讽的，主角始终没成为骑士；本灵感把它反转，让幻想成真。空位：xxx 未定，留到第1步，用不同的 xxx 拉开方案。

| 元素 | 原文写法 | 核心/可替换 | 还可以是 |
| --- | --- | --- | --- |
| 幻想自己是某个身份 | 幻想自己是xxx | 核心 | — |
| 身份是什么 | xxx | 可替换（空位，留到第1步） | 骑士、守护者、老虎、魔法师…… |
| 幻想与现实的落差 | 被人嘲笑 | 可替换 | 无人知晓、自己都不信、没人当真、只是游戏 |
| 考验的性质 | 危难 | 可替换 | 不公、事故、外敌、身边人的困境 |
| 挺身而出 | 挺身而出 | 核心 | — |
| 真的成为那个身份 | 成为了真正的xxx | 核心（火花） | — |
| 成真的方式 | 未指定 | 可替换 | 发生在别人眼里、戏与真重合、画面象征、字面成真 |

## 第1步 内核

### 思路表（节选 5 行，实际给了 13 行）

| 思路 | 主角 | 幻想的身份 | 考验 | 挺身而出 | 高潮点（假变真的那一刻） |
| --- | --- | --- | --- | --- | --- |

### 选定的内核

用户选 5「小老虎」，逐属性微调后定稿。

**内核**：一只总幻想自己是老虎的小猫，在狼群来袭时站了出来，让小动物们撤——那一刻，它的影子化作了老虎。

- 主角：小猫
- 幻想的身份：老虎
- 考验：狼群来袭
- 挺身而出：站出来，让小动物们撤
- 高潮：影子化作老虎

## 第2步 情节骨架

载体与体量：连环画，约 40 页，每页一个刺激点，全片约 40 个。按 25%：50%：25%，第一幕 10 个、第二幕 20 个、第三幕 10 个。

高潮相关价值：主角的信念。

| 幕 | 节点 | 内容 | 状态 |
| --- | --- | --- | --- |
| — | 弧线 | 高-低-高：信念被现实击碎，最后明知不是仍挺身而出。第二幕起伏 3 次（↓ ↑ ↓），终点是信念彻底破碎 | 已定 |
| 第一幕 | 起点 | 小猫坚信自己是老虎 | 已定（内核） |
| 第二幕 | 起伏① ↓ | 林子里来了一只流浪猫，伙伴们都说它俩长得一模一样，流浪猫还亲热地叫它“兄弟”；它嘴上不认，心里开始不踏实 | 已定 |
| 第二幕 | 起伏② ↑ | 偶遇一个大狗熊，它出手，大狗熊碰巧走了；大家夸赞它，它再次有了信心 | 已定 |
| 第二幕 | 起伏③ ↓（第二幕终点） | 听说狼要来了，它去对付狼，却被很轻易地击败；被救回来后，它将自己关在屋子中，信念破碎 | 已定 |
| 第三幕 | 加码 | 狼群到了 → 大家要撤，它跟在大家之中 → 撤离的路被挡住了，只能换路 | 已定 |
| 第三幕 | 最终选择 | 狼群终于追上来了，小动物很多没跟上来（算高潮部分的开头）→ 自己逃命，还是留下拖住狼群让大家撤 | 已定 |
| 第三幕 | 高潮 | 它站出来让小动物们撤，影子化作老虎；定格在老虎影子上，不交代狼群是否退去 | 已定（内核） |
| 结尾 | 结尾 | 必须是结尾战神；具体内容后续专门设计 | 暂缓 |

过程：起伏次数按 20 页定为 3 次；倒着定，先定③（终点，由内核决定：信念彻底破碎），再定②、①。①的候选里出现过“对付乌鸦”，被用户否掉：后两次已经是对付大狗熊、对付狼，不能都是对付。

前后对照检查（已定）：
- 对付狼就是故事的主线，第二幕起伏③和第三幕“狼群到了”不重复。
- 狼来了大家要撤，它跟在大家之中，其它的不用太精细。
- 在第二幕中，伙伴们也和它一样的认识历程：觉得好像不是、后来觉得是。

## 第3步 分场

世界观：童话寓言风，世界只简单交代，不展开规则，够讲明白故事就行。

高潮的呈现方式：影子化作老虎没有真的发生，只是画面呈现；高潮定格在老虎影子上，不交代狼群是否退去。

分场表：加粗行是框架节点，下面挂它的场次；页数＝刺激点数（每页一个），全片 8 场、40 页。场1、场6 的场景内容已按第4步的节拍表更新。

| 节点 / 场 | 页数 | 场景内容 |
| --- | --- | --- |
| **第一幕·起点**：小猫坚信自己是老虎 |  |  |
| 场1 初始状态 | 6 | 听说老虎有一身条纹，它对着水面把“老虎长什么样”逐条比对（条纹、胡子、尾巴都有，个头跳过），认定自己是老虎；它跳上树桩威严宣布，却只“喵”了一声；伙伴们没有不信，郑重地认了它。刺猬想起老虎额头上还有个“王”字，老乌龟说“年纪小，还没长出来”，它却心虚；夜里偷偷用泥巴画了一个，第二天顶着王字亮相，伙伴们都说“王字长出来了” |
| 场2 入局 | 4 | 小动物们一起推举它当林子的守护者，给它戴上树叶编的王冠；它郑重答应要保护大家 |
| **第二幕·起伏① ↓**：信念第一次动摇 |  |  |
| 场3 流浪猫 | 5 | 林子里来了一只流浪猫，伙伴们都说它俩长得一模一样，流浪猫还亲热地叫它“兄弟”；它嘴上不认，心里开始不踏实，伙伴们也觉得好像不是 |
| **第二幕·起伏② ↑**：重拾信心 |  |  |
| 场4 大狗熊 | 6 | 偶遇一个大狗熊，猫猫出手，大狗熊碰巧走了；大家夸赞它，它再次有了信心，伙伴们也觉得它是老虎 |
| **第二幕·起伏③ ↓（第二幕终点）**：信念彻底破碎 |  |  |
| 场5 对付狼 | 9 | 听说狼要来了，它站了出来去对付狼，却被很轻易地击败；被救回来后，它将自己关在屋子中，信念破碎。内核的展现，第二幕最长。提醒：第二幕最后情节之后，要有情绪氛围的加码戏，来展现高潮价值至此的转换（也因此，第二幕这里才会加长）。 |
| **第三幕·加码①**：狼群到了 |  |  |
| 场6 撤离 | 2 | 狼群到了，大家要撤，它跟在大家之中 |
| **第三幕·加码②**：撤离的路被挡住，只能换路 |  |  |
| 场7 换路 | 2 | 撤离的路，被挡住了。只能换路 |
| **第三幕·最终选择＋高潮**：狼群终于追上来 → 自己逃命，还是留下拖住狼群让大家撤 → 它站出来，影子化作老虎 |  |  |
| 场8 转身 | 6 | 狼群终于追上来了。小动物很多没跟上来。自己逃命，还是留下拖住狼群让大家撤；它站出来让大家撤，影子化作老虎，定格，不交代狼群是否退去。“狼群终于追上来”算高潮部分的开头。全片核心，第三幕最长 |
| **结尾**：必须是结尾战神；具体内容（含回响）后续专门设计 |  |  |

分场时的两次纠正（照此分场）：
- 起伏②（打走大狗熊、大家夸它、重拾信心）是一个整体，只能是一场，不能拆成两场。
- “被狼群追上”这个加码，和最终选择、高潮不能混在一场；后来按第4步的需要，“狼群终于追上来”挪进场8，算高潮部分的开头，场7 改成“换路”，编剧档案和刺激点文档都同步改了。
